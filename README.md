# Skin Cancer Classification

A deep learning project for multi-class skin lesion classification using **EfficientNet-B4** and transfer learning.

## Highlights

✓ EfficientNet-B4
✓ Transfer Learning
✓ PyTorch & CUDA
✓ Data Augmentation
✓ Class Weighting
✓ Label Smoothing
✓ Best Validation Accuracy: **94.73%**

## Model

The project uses a pretrained **EfficientNet-B4** model and fine-tunes it for skin lesion classification. Training includes data augmentation, class weighting, and label smoothing to improve model performance.

## Results

**Best Validation Accuracy: 94.73%**
